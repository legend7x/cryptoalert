# Crypto Alert — Android

هذا مشروع Python/Kivy جاهز لمحاولة إنتاج APK عبر Buildozer. لم يتم بناء APK أو اختباره على جهاز Android في هذه البيئة.

## إنشاء APK عبر GitHub Actions
1. أنشئ مستودع GitHub جديدًا.
2. ارفع جميع الملفات والمجلد `.github` إلى جذر المستودع مع الاحتفاظ بمساره.
3. افتح تبويب Actions ثم اختر `Build Android APK`، واضغط `Run workflow`.
4. بعد اكتمال البناء بنجاح، افتح التشغيل وانزل إلى قسم Artifacts وحمّل `CryptoAlert-APK`.
5. فك ضغط ملف artifact لتحصل على ملف `.apk`، وثبته على هاتفك.

## على Linux
```bash
python3 -m pip install --user buildozer 'cython==0.29.34'
buildozer -v android debug
```
سيظهر APK في مجلد `bin/` إذا نجح البناء.

## ملاحظات
- تم تفعيل إشعار من التطبيق نفسه بواسطة `plyer` عند الوصول للسعر المستهدف.
- المراقبة الحالية تعمل أثناء نشاط التطبيق، ولا تضمن تنبيهات عند إغلاقه أو توقفه بالخلفية.
- `service.py` ملف أصلي مستقل يحتوي إعدادات ثابتة لـ BTC ولا يتم تشغيله تلقائياً، حتى لا يعطي انطباعاً غير صحيح عن تنبيهات الخلفية.
- يحتاج التطبيق إلى الإنترنت. وعلى Android 13+ قد تحتاج إلى منح إذن الإشعارات من إعدادات التطبيق.
- يمكن أن تتطلب بيئة البناء تعديل إصدار SDK أو NDK أو بعض الاعتماديات، بناءً على أخطاء سجل البناء.
